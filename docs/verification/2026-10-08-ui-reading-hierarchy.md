# 全站排版与字体优化交付记录

用户要求处理布局凌乱、重点难找，并在过程中补充优化全局字体。工作于2026-10-07开始，2026-10-08完成验证。

## 布局与信息层级

- 首页：`app/home-front/front-modules.tsx` 与 `home-front.css` 将申论、面试的首个方法入口标为“从这里开始”，拉开主要入口、其余入口、每日积累和编者按的权重。保留八个栏目和手机端入口说明。取消悬停改变padding造成的位移，修正手机上下排列时遗留的左右分栏内边距。
- 栏目：`app/learning-page-frame.tsx` 与CSS改为随内容增长的标题区，删除重复眉题和大号装饰章，保留全部章节入口。删除 `desktop-readability.css` 的620px固定高度。
- 阅读：目录由左右并排的章/细目改为上下层级，宽度224–248px，保留整栏收起、手机抽屉、定位和焦点行为。正文外层100–110px重复留白移除；写作页使用同一内容间距变量。
- 重点：`app/learning-reading-guide.tsx` 与CSS把三列重点改为顺读清单，练习在桌面旁列、手机下方；删除多余装饰线。`editorial-reading.css`降低正文内重复大标题的尺寸，统一小标题、引言和段落的节奏。
- 遮挡：`floating-study-dock.tsx`与CSS增加原生details“收起音乐/显示音乐”。收起只隐藏视觉区域，音频元素保持挂载，资料入口仍可用。页脚留180px下边距，移动目录触发按钮增加标签间距。

## 全局文字角色

`app/globals.css`建立字体与字号变量，`app/site-typography.css`由根布局加载：

- 标题采用系统宋体系列；正文与操作采用苹方/微软雅黑等无衬线中文字体。
- 主要文章正文桌面17px、手机16px，行高1.9；导航和目录操作14–15px，辅助文字按角色分级。
- 页标题、二至四级标题采用一致的字号范围和更适合多行中文的行高，取消不必要的负字距；数字使用等宽数字对齐。
- 覆盖方法正文、写作文章、案例、技巧文章、面试内容与资料笔记；引言重点保留宋体强调。没有下载外部字体或增加项目依赖。

## 简化与验证

- 更新 `tests/desktop-readability.test.mjs`：不再把固定620px当作成功条件。更新首页测试：手机说明应保留，不允许用CSS注释中的旧代码骗过断言。
- 201项测试、ESLint和TypeScript通过；根路径和GitHub Pages两种静态构建及资产校验通过。
- 浏览器逐一切换八个栏目的全部36个章节入口，确认目录当前项与重点提示同步；目录收起、手机抽屉选择后关闭均通过。
- 320、390、820、1041、1100、1440px视口检查了对应布局与字体，未发现横向溢出。
- 桌面正文实际计算字体为PingFang SC / Microsoft YaHei等，17px/32.3px行高；手机16px/30.4px。资料标签从原11px提高为13px。
- 原1440×1000页面头部620px，重点距页面顶部约811–921px；新版本一般栏目头部318px，重点距顶部434px。写作页因八个入口头部441px，重点557px，均保留全部章节。
- 双级目录从380px缩为248px；普通目录从252px缩为224px。
- 播放后收起音乐，确认同一音频元素仍连接且继续播放，资料面板可正常打开，重新显示后可暂停。
- 视觉截图复核确认标题/正文搭配、学习起点、重点清单与目录层次成立；保留用户对最终审美的判断。截图保存在本机output/playwright/layout-*。

## 限制与后续

早期持续运行的预览会话出现生成文件与浏览器DOM不一致；重新构建、使用独立预览目录和新浏览器后已验证最新结构。不能据此确定用户之前旧页面的成因。

系统字体会因设备安装情况有所区别；保留字体回退。本轮统一的是主要文字角色，不会覆盖示意图内文字、公文落款等特殊语义排版。音乐展开时仍占屏幕空间，可使用“收起音乐”继续阅读。

真实二维码仍未提供，本轮没有把扫码领取标为完成。资料弹层继续显示未开放状态和站内资料库入口。

沿用既有master流程发布GitHub Pages与EdgeOne，线上版本与复验结果在交付消息中说明。
