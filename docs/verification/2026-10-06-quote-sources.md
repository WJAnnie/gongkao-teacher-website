# 名人箴言来源核查记录

核查日期：2026-10-06

范围：`app/shenlun/writing/writing-quote-library.ts` 的 262 条、12 类素材。分类数量未删减：11 个主题类各 20 条，通用哲理 42 条。

## 本轮实际处理

- 为 262 条补齐 `sourceUrl` 与 `sourceNote`，来源解析集中在 `writing-quote-sources.ts`。
- 实际替换名言条目 44 条：主要把无法定位单篇依据的“高频表述”“多次重要讲话”“人民日报评论”类素材，改为同主题的官方原句或可核验中国古语。
- 当前覆盖：262 条均有来源链接和说明；去重来源 URL 155 个，去重来源说明 170 个。
- 覆盖类型分为两类：官方网页查证（gov.cn、qstheory.cn、部门官网、人民网具体文章等）和公版全文/古籍篇章链接（ctext、维基文库、马克思主义文库等）。

## 测试约束

`tests/writing-quote-sources.test.mjs` 已增加约束：

- 禁止 `people.com.cn`、`qstheory.cn`、`gov.cn` 等域名首页作为来源。
- 禁止 `待继续`、`再检索`、`检索入口`、`公开库`、`全文入口`、`按篇名复核`、`申论素材化`、`评论表述` 等掩盖性说明。
- 校验每类数量、链接格式、来源说明、同文同出处一致性、来源域名白名单。

当前该测试 4/4 通过；`npm run typecheck` 与 `npm run lint` 也通过。

## 已知边界

主代理收尾时增加了分类内去重和间接归属检查，删除了把“相关主题得到支持”当作原话出处的做法。找不到直接依据的条目改用公版古语；逐条保留来源链接、具体篇目和使用语境。

最终收尾：

- 无法逐字确认的生态概括、官媒概括等条目已替换为有具体篇章的古语。
- 对含糊的《后汉书》引语不再保留不一致来源，改用已核对的公版引语。
- 补充同分类内重复词条，使十一主题类各有二十条不同引语、通用哲理四十二条不同引语。
- 校正博物馆文物引语的2014年联合国教科文组织演讲出处，以及“国无德不兴”的2014年北大讲话出处。
- 删除媒体首页及通用评论兜底，未登记具体出处的新条目会直接报错，不会自动赋予官方来源。

新增或替换的古语采用维基文库《论语》具体篇章全文，对照原文用字并转为简体。剩余既有出处保持可追溯；链接可访问性受外站策略影响，本轮不承诺外站永久可用。内容与来源结构测试最终为5/5通过。
