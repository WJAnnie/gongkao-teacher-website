# 写作积累单页目录与全站文案优化实施计划

## 目标

将 `/shenlun/writing/` 从多层静态入口改为同页学习手册：Hero、左侧目录、URL 和右侧正文共用八个模块的状态。删除八个核心学习页 Hero 与正文之间重复的介绍屏，并对全站学生可见原创文案做自然中文审校。

## 不变边界

- 不改首页结构、真题原文、材料原文、政策表述、引文、出处和数据事实。
- 不新增依赖，不删除旧写作路由；旧路由只负责兼容定位。
- 热点、案例继续按分类动态导入并缓存，首页不得直接导入全部正文。
- 比喻词库与对仗句库只有两级目录；其余模块只使用真实存在的层级。
- 全站教师称谓统一为“云帆老师”，英文标识为 `YUNFAN`。

## 实施顺序

1. 先用测试锁定八模块 Hero、左侧树、同页切换、旧链接定位、内容数量和禁用文案。
2. 把写作章节元数据从四组改为八模块，复用共享 Hero 过渡与移动端目录。
3. 将 `WritingLibraryManual` 接入共享 `LearningContentFrame`，实现单路径展开、面包屑、全库搜索、hash 恢复和 session 记忆。
4. 新增五个不完整模块的原创教学数据与差异化正文组件；保留热点、案例、比喻现有语料和按需加载边界。
5. 旧 `/hotspots`、`/cases`、`/metaphors` 及分类路由改为定位入口，不再形成新的视觉层级。
6. 删除八个核心页重复介绍屏，保留真实正文标题。
7. 使用 `humanizer-zh` 审校全站原创 UI/说明文案，清理项目状态、实现方式和无意义英文装饰语。
8. 依次执行 lint、typecheck、测试、两种静态构建及桌面/平板/手机视觉检查。

## 验收

- 写作 Hero 和左侧一级目录均为八个模块。
- 一级只展开一个；三级模块只展开一个二级；叶子选中后右侧立即显示具体内容。
- 对仗句库、比喻词库止于二级。
- 搜索结果可跨模块定位，刷新恢复 hash，模块间切换恢复最近位置。
- 旧深层 URL 可访问并定位到相应模块、分类和条目。
- 页面不出现“下一轮、继续建设、静态页面、一次加载、扩容、脚本异常”等面向开发者的文案。
- 所有自动化验证通过；无法完成的真实浏览器检查必须明确记录，不伪造结论。
