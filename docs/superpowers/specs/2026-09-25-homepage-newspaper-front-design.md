# 首页「报刊头版」重设计

## 目标

把首页改成一张《答卷之外》的报纸头版：学生打开首页，第一屏就能看到并直接进入申论、面试共八个学习模块，同时看到每天轮换的热点时评和规范用词，知道站里有真实、持续的内容。

本轮要解决现有首页的六个问题：

1. 学习目录默认折叠，要点「展开」才看到八个模块。
2. 学习入口重复三套：首屏目录、「从这里继续往下学」、首页手机顶部导航。
3. 首屏的吸顶滚动动画让第二屏几乎空白，只剩一团光斑。
4. 「向岸」播放器悬浮在内容上方，桌面端盖住「课程现场」「获取资料」，手机端挡住「面试学习」一行。
5. 单字掉行（「学」「楚。」）和 6–9px 的小字看不清。
6. 首页看不到站内任何实际内容。

## 适用范围

- 只改首页 `/`，不改任何学习页、写作积累页或其他路由。
- 不新增第三方依赖。
- 保留：品牌名「答卷之外」、标语「把公考题做懂，把话说清」、「云帆老师」称呼、宋体标题、纸张底色、歌曲「向岸」及其同步歌词。
- 继续满足现有测试约束：学生可见文案使用「云帆老师」，不出现装饰性英文标签。

## 视觉语言

- **底色与墨色**：沿用 `--paper: #f4f0e7`、`--ink: #25251f`。
- **唯一强调色**：朱红印章色 `#a84b3f`（与现有 `tone-red` 同值），只用在印章、模块序号、分类小标、标语中的「说清」和规范用词的箭头上。首页不出现四个模块主题色，学习页内的主题色保持不变。
- **去掉**：珊瑚粉渐变、黄绿光斑（pointer glow）、背景网格、环形「阅」字轨道、描边标题、滚动进度条、吸顶滚动叙事。
- **字体**：标题、栏目名、模块名用现有宋体栈 `"Songti SC", "SimSun", Georgia, serif`；正文与小字用现有无衬线栈。序号可以用 Georgia 斜体。任何文字不小于 12px。
- **分隔**：报头下用粗细双线，栏目之间用 1px 竖线，条目之间用点线，下栏与编者按上方用双线。
- **动效**：不做入场和滚动动效，只保留链接悬停和聚焦状态。
- **断行**：标题与栏目名设置 `text-wrap: balance`，标语使用固定断行，保证不出现单字孤行。

## 版面结构

桌面端从上到下：

1. **报头**
   - 顶行左侧「申论 × 结构化面试 · 长期学习站」，右侧「云帆老师 主编」。
   - 居中大号宋体「答卷之外」，旁边一枚朱红方印「云帆之印」。
   - 粗细双线下是日期行：左侧「九月号 · 今日 九月二十五日」（按当天日期生成），中间「方法 · 真题 · 积累 · 课堂」，右侧锚点导航「学习入口 ｜ 编者按 ｜ 获取资料」。
2. **头条**：左侧大标语「把公考题做懂，/把话说清。」；右侧竖线隔开「写在前面」两三句手记，署名「—— 云帆老师」。
3. **三栏**（`id="study"`）
   - **申论版**：01 方法框架、02 真题精练、03 写作积累、04 课程现场，每项下一行说明小字（沿用现有 `desc` 文案）。
   - **面试版**：01 题型方法、02 真题实战、03 表达训练、04 课程现场，结构同上。
   - **今日热点**：三篇热点时评，每篇显示分类名和标题，点标题打开原文；栏底放「全部热点时评 ↗」。
4. **下栏**（上方双线）
   - **规范用词**：今日三则，左侧材料口语（灰色），中间朱红箭头，右侧规范表达（宋体加粗）。
   - **副刊 · 向岸**：两行歌词节选，播放按钮、进度条、时长和「歌词」开关。
   - **获取资料**（`id="contact"`）：二维码加说明文字。
5. **编者按**（`id="about"`，上方双线）：四小段并排——我在教什么、为什么做这个站、这里有什么、怎么使用，内容从现有「关于我」四块压缩而来。原有标签组和插画 `about-study-art.svg` 不再使用。
6. **页脚**：「答卷之外 · 云帆老师 · 申论 × 结构化面试」与「返回顶部 ↑」。

手机端（沿用站内现有断点，宽度不大于 760px）：

- 所有栏目按上面的顺序叠成一栏，栏目之间用 1px 横线。
- 模块只显示序号和名称，说明小字隐藏，每项整行可点。
- 编者按四段纵向排列。
- 播放器就是「副刊」栏里的一块，不固定在屏幕底部。
- 首页不再显示手机顶部的「申论 / 面试」下拉导航。

视觉参照为头脑风暴会话中的第二版样稿（`.superpowers/brainstorm/…/content/newspaper-front-v2.html`，不入库）。

## 每日轮换

### 数据来源

- **热点**：构建时（服务端组件）调用现有 `loadAllHotspotArticles()` 和分类表 `hotspotArticleCategory` / `hotspotTaxonomy`，抽出轻量索引 `{ slug, title, categoryKey, categoryLabel }`，以 props 传给客户端组件。正文、导语、标签等字段不进入首页的客户端包。
- **规范用词**：`termLibrary`（十一类，每类五十条）条目本身很短，同样在服务端展平为 `{ before, after, categoryKey }` 列表后传入。

### 挑选规则

- 以北京时间（`Asia/Shanghai`）的当天日期 `YYYY-MM-DD` 作为种子。
- 用一个确定性的纯函数，从列表中挑出三个互不重复的下标：同一天、同一份数据，所有访客结果相同；换一天结果改变。
- 热点优先挑三个不同分类的文章；分类不足三类时再允许重复分类。
- 规范用词同样挑三条，尽量来自不同分类。
- 报头月份取同一个日期：「九月号」，日期行显示「今日 九月二十五日」，月、日都用中文数字。

### 渲染时机

- 静态导出时先按构建当天的日期渲染，保证无脚本时页面完整。
- 浏览器加载后在 `useEffect` 中按访客当天日期重新计算；结果不同才替换，避免水合不一致警告。

### 链接

- 热点标题链接到 `/shenlun/writing/#hotspots/<categoryKey>/<slug>`，写作积累页现有的 hash 路由会直接打开该篇。
- 「全部热点时评」链接到 `/shenlun/writing/hotspots/`。
- 规范用词不单独设链接，栏目标题链接到 `/shenlun/writing/#terms/<当天第一条的 categoryKey>`。
- 所有站内链接与现有学习入口 `LearningEntryLink` 的写法保持一致，保证在正式站子路径下与现有入口表现相同。

## 组件划分

新建目录 `app/home-front/`，每个文件只负责一件事：

| 文件 | 职责 |
|------|------|
| `front-date.ts` | 纯函数：取北京时间日期、生成中文月日、由日期生成种子 |
| `front-picks.ts` | 纯函数：按种子从列表挑 N 个不重复条目、优先不同分类 |
| `front-data.ts` | 服务端：从热点注册表和规范用词库构建轻量索引 |
| `front-masthead.tsx` | 报头与日期行（客户端日期修正） |
| `front-daily.tsx` | 今日热点栏与规范用词栏（客户端轮换） |
| `front-song.tsx` | 副刊栏，包裹内嵌模式的播放器 |
| `home-front.css` | 首页全部样式 |

`app/page.tsx` 改为组合上述组件；八个模块入口直接复用 `learning-routes.ts` 中的 `shenlunRoutes` / `interviewRoutes`，说明文案从 `subject-gateway.tsx` 移入 `learning-routes.ts` 旁的展示数据，避免两处重复。

### 播放器

- `HomeSongPlayer` 改为内嵌模式：保留音频加载、播放/暂停、进度拖动、时长、同步歌词、加载失败重试。
- 去掉滚动到 `#about` 才出现、关闭、重新打开的逻辑及对应的固定定位样式。
- 歌词列表在栏内展开，不遮挡其他栏目。

### 删除与清理

- 从首页移除：`SubjectGateway`、`HomeLearningRepeat`、`MotionLayer`、首页手机顶部导航 `home-mobile-learning-nav`。
- 候选删除的样式文件：`subject-gateway.css`、`home-learning-repeat.css`、`home-about.css`、`home-refresh.css`、`hero-review-orbit.css`、`hero-content-index.css`、`home-song-placement.css`、`mobile-home-learning-nav.css`，以及 `globals.css` / `mobile-refinement.css` 中只服务旧首页的规则。
- **删除前逐个核实**：文件内的选择器若在首页以外的组件中仍被使用，则保留该规则（必要时迁到对应页面的样式文件），只删确认无引用的部分。
- 组件文件在确认无其他引用后删除。

## 测试

新增 `tests/home-front.test.mjs`：

- `front-date`：给定 UTC 时间，返回正确的北京时间日期（覆盖跨零点情况）；中文月日格式正确。
- `front-picks`：同一种子结果相同；不同种子结果不同；三个结果互不重复；分类足够时三篇分属不同分类；列表少于三条时不报错。
- `front-data`：热点索引条目数与热点库一致，每条都有 slug、标题和已登记分类；索引不含正文字段。
- 首页源码：包含八个模块的链接；不再包含「展开」按钮、`SubjectGateway`、`HomeLearningRepeat`、`MotionLayer`；热点链接符合 `#hotspots/<分类>/<slug>` 格式。

调整现有测试：

- `tests/home-song.test.mjs`：去掉对浮现、关闭、重新打开行为的断言，补充内嵌模式的断言；歌词和错误重试断言保留。
- 原有「云帆老师」「不出现装饰性英文」约束保持通过。

验收：

- `npm test`、类型检查和构建全部通过。
- 用 Playwright 截取桌面 1440 与手机 390 宽度的整页截图，逐项核对版面结构，确认没有元素遮挡、单字孤行和小于 12px 的文字。
