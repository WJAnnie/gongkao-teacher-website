# 全站阅读层级与布局整理

用户反馈整体排版杂乱、重点难找。保留米纸、宋体与科目色的既有方向，用Oil UI既有界面深化路径整理信息权重。

实测1440×1000：八个核心栏目共用620px首屏；抽样正文重点距顶部811–921px，框架/写作双列目录宽380px。页面在正文出现前占用过多空间，目录和重点提示内部也存在过多并列关系。

## 本轮范围

1. 栏目首屏改为正常文档流：主题标题、简介、章节入口按顺序排列，去掉重复眉题和装饰印章。取消固定高度和绝对定位，保留全部可操作章节入口。
2. 阅读框目录控制在约224–248px，章与细目上下排列；保留整栏收起、移动抽屉、当前定位和键盘行为。正文获得更多宽度。
3. 本节重点使用三条顺读清单，练习置于清单之后；统一标题、正文和注释权重，减少小字和边线。
4. 首页强化两个科目的第一步，降低其余入口与每日积累、编者按的竞争；不删除课程或资料内容。
5. 清理本次取代的首屏定位和固定高度规则，更新受影响旧测试；不追加依赖、改数据架构或重写内容库。
6. 根据用户后续要求，统一全局字体角色：宋体标题、无衬线正文/操作，数字等宽对齐；正文桌面17px、手机16px，说明不低于12px，并统一多行标题与正文行距。复用本机中文字体，不引入字体网络依赖。
7. 唱片窗支持单独收起以腾出阅读空间，音乐不因收起而卸载，二维码入口保留。

先保留基线截图与既有行为测试，再修改。验证八个栏目入口/切章/目录收起与手机抽屉、320/390/820/1100/1440视口、重点可见位置和横向溢出；检查代表性正文、资料入口和唱片。截图审视、lint/typecheck/测试、两种静态构建后发布并复验。

真实二维码仍待用户提供，与本轮布局优化分开记录，不能将其标为已完成。
