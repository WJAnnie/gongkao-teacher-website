## 为什么做这个站

「答卷之外」最初是一位申论与面试老师的个人内容站，现在正在升级为一个更完整的 **申论 × 面试学习平台**。

它不准备扩张成全科公考百科，而是希望把两门主科做深：

1. **学方法**：知道题型真正考什么、材料怎么读、观点怎么形成；
2. **做真题**：按年份、考试、题型和主题定位练习；
3. **限时练**：把“会做”逐渐训练成“考场上做得出来”；
4. **答后自检**：检查任务、结构、论据、表达和闭环；
5. **复盘迁移**：记录一次错误，让下一道题少犯一次。

网站借鉴优秀公考知识站的**内容组织方式和学习闭环**，但保留自己的视觉语言，不复制其他网站的 UI。

## 当前已经有什么

### 1. 真题 / 专项题库

首批题库包含 **48 条可筛选题目索引**：

- **申论 30 条**：2020—2025 国考地市级，每年 5 个主要作答任务；
- **面试 14 条**：2024—2026 税务系统公开考生回忆题索引；
- **原创专项 4 条**：用于补足真题没有覆盖的新热点和新场景。

题库支持：

- 申论 / 面试筛选；
- 题型筛选；
- 年份、主题、关键词搜索；
- 随机抽题；
- 每题展示考试、题型、主题、题意摘要、训练重点和来源性质。

> 真题区以**题意摘要与训练索引**为主，不未经许可复制第三方机构的整套材料或答案。完整材料后续优先使用公开、合法、自行整理或获得授权的来源。

### 2. 学习资料库

资料先按 8 条长期学习线组织：

- 申论入门
- 小题方法
- 文章写作
- 面试方法
- 表达训练
- 热点素材
- 规范表达
- 晨读积累

目前已经加入首批 **24 篇原创学习笔记**。每篇不是只有标题，而是包含：

- 方法说明；
- 核心检查点；
- 常见训练思路；
- 一个可以马上完成的小练习。

资料页支持按申论 / 面试 / 申面共用、资料分类和关键词筛选，并可直接展开阅读。

### 3. 训练工具箱

当前已经可以使用：

- **答题计时器**：面试 3 分钟、申论小题 20 分钟、作文 60 分钟；
- **作答草稿 / 字数统计**：用于申论答案、面试提纲和复盘；
- **答后自检**：从任务、结构、论据、套话和闭环进行快速检查；
- **练习记录**：将最近练习保存在当前浏览器的 `localStorage` 中。

后续计划增加收藏 / 错题本、每日一题、模拟考试和学习进度统计。

### 4. 首页内容体系

首页仍然保留原来的个人教师气质，包括：

- 「你现在卡在哪？」学习入口；
- 学习中心；
- 深度内容档案；
- 真实课堂切片预留；
- 从材料到表达的训练路径；
- 申面共用素材地图；
- 老师介绍与联系方式。

首页负责“认识这个站和找到学习入口”，大量题目和资料则逐步沉淀到独立学习页面，避免所有内容都挤在一个超长首页中。

## 设计原则

内容可以越来越多，但视觉风格不因为“做知识库”而突然换皮。

当前继续使用：

- 纸张质感浅色背景；
- 宋体大标题 + 现代无衬线正文；
- 酸绿色、橙色、蓝色强调色；
- 细线、编号、档案卡片等编辑设计元素；
- 滚动驱动 Hero、内容档案和方法路径动效；
- 桌面端与移动端响应式布局。

**原则：参考优秀公考网站的内容丰富度与学习体验，不复制其设计风格。**

## 内容原则

这个站希望长期坚持几件事：

- 只专注申论与结构化面试，不为了“大而全”扩张全科；
- 不押万能模板；
- 不为了显得专业而虚构教师履历、成绩或学员成果；
- 真题来源性质尽量标清；
- 不直接搬运第三方机构整套课程、讲义或答案；
- 素材必须能服务观点；
- 方法必须能落到一道具体练习；
- 每一次练习尽量留下可以迁移到下一题的东西。

## 本地开发

建议 Node.js 22 或更高版本。

```bash
git clone https://github.com/WJAnnie/gongkao-teacher-website.git
cd gongkao-teacher-website
npm install
npm run dev
```

## 构建

普通构建：

```bash
npm run build
```

生成静态站点：

```bash
npm run build:static
```

静态脚本当前会导出：

```text
/
/questions/
/materials/
/tools/
```

产物整理到 `site/`，供 GitHub Pages / EdgeOne Pages 发布。

## 自动部署

### GitHub Pages

`.github/workflows/deploy-pages.yml` 监听 `master`。合并到正式分支后会自动安装依赖、构建静态站点并发布。

正式访问：

**https://wjannie.github.io/gongkao-teacher-website/**

### EdgeOne Pages

`.github/workflows/deploy-edgeone.yml` 负责正式 EdgeOne 部署。

开发分支另有 Preview 工作流用于上线前视觉确认。Preview 地址可能由 EdgeOne 返回带时效参数的链接，因此不会把一次性 token 固化进 README。
